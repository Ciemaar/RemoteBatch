# Sources Considered

This file tracks the sources used in the development and modernization of this project.

- [uv documentation](https://docs.astral.sh/uv/): Used for understanding the `uv` environment management and locking processes.
- [Pyright Configuration](https://microsoft.github.io/pyright/#/configuration): Used to correctly configure pyright to use strict mode.
- [Click Documentation](https://click.palletsprojects.com/): Used to understand how to build CLI applications and write robust tests using `CliRunner`.
- [Ruff Documentation](https://docs.astral.sh/ruff/): Used for configuring ruff formatting and linting.
